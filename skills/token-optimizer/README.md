# Token Optimizer

**The best skill to stop wasting tokens.**

Claude often spends tokens you don't need: long intros, repeated explanations, extra searches and huge chats. Token Optimizer cuts that waste without losing accuracy or quality.

## What it does

- **Short, direct answers.** It goes straight to the point, with no filler.
- **3 brevity levels.** Say "level 1", "level 2" or "level 3" to choose how short you want it.
- **Fewer tools and searches.** It only uses them when they are really needed.
- **Long chats under control.** It tells you when it's time for a new chat and writes a handoff summary, so you lose nothing.
- **Accuracy first.** It never cuts figures, code or warnings that matter.
- **Works in chat and in Claude Code / Cowork.**

## How to use it

It is meant to run by default in every chat. You can also call it by asking for "be concise", "save tokens", "level 3", "handoff summary" or mention "Token Optimizer". It also steps in when a chat gets very long.

# Token Optimizer (Español)

**La mejor skill para dejar de malgastar tokens.**

Claude a veces gasta tokens que no necesitas: introducciones largas, explicaciones repetidas, búsquedas de más y chats enormes. Token Optimizer recorta ese gasto sin perder precisión ni calidad.

## Qué hace

- **Respuestas cortas y directas.** Va al grano, sin relleno.
- **3 niveles de brevedad.** Di "nivel 1", "nivel 2" o "nivel 3" para elegir lo corta que la quieres.
- **Menos herramientas y búsquedas.** Solo las usa cuando de verdad hacen falta.
- **Chats largos bajo control.** Te avisa cuando conviene abrir un chat nuevo y escribe un resumen de traspaso para que no pierdas nada.
- **Primero la precisión.** Nunca recorta cifras, código ni avisos importantes.
- **Funciona en el chat y en Claude Code / Cowork.**

## Cómo usarla

Está pensada para actuar por defecto en todos los chats. También puedes invocarla pidiendo "sé conciso", "ahorra tokens", "nivel 3", "resumen de traspaso" o menciona "Token Optimizer". Además interviene cuando un chat se hace muy largo.
