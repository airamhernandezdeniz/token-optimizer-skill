# Resumen de traspaso

Para continuar en un chat nuevo sin arrastrar el historial. Escríbelo en el idioma del usuario, en un solo bloque listo para copiar, de unas 250 palabras como máximo (más solo si incluye código final).

## Plantilla

```
# Traspaso: <tema en pocas palabras>

Objetivo: <qué quiere conseguir el usuario>
Decisiones: <lo elegido y por qué, en una línea cada una>
Hecho: <estado actual>
Código o comandos finales: <solo lo adoptado>
Datos clave: <versiones, nombres, rutas, cifras>
Pendiente: <siguiente paso y dudas abiertas>
Preferencias: <formato, tono o nivel de brevedad si importan>
```

## Reglas
- Incluye solo lo que cambia lo que se hará después; omite apartados vacíos.
- Excluye errores, intentos descartados, explicaciones exploratorias y cortesías.
- Cifras, fechas, nombres y código, exactos; si algo no está claro, márcalo como "sin confirmar" en vez de inventarlo.
- Termina con una frase: "Pega esto al empezar el chat nuevo."
