# Changelog

Format: newest first. / Formato: lo más nuevo arriba.

## [1.3.0] - 2026-11-22
- Description now opens with the "best skill to stop wasting tokens" pitch.
- Always-on: applies by default from the first message and stays active for the whole chat.
- More trigger phrases in English and Spanish (short answers, summarized, "Token Optimizer", "optimizar tokens"...).

## [1.2.0] - 2026-11-22
- Ideas adapted from the open-source skills token-saver and token-shield (both MIT).
- New metric: tokens per accepted result.
- Advice on fixed context: disable unused skills, plugins and connectors; avoid overlapping skills.
- New `references/terminal.md` for Claude Code / Cowork: sessions, checkpoints, tool output, subagents, memory.
- Honest limits: no invented savings figures.
- License: English and Spanish, credit requested, contact email, acknowledgements.

## [1.1.0] - 2026-11-21
- Brevity levels 1, 2 and 3.
- Topic-change and long-chat detection with a new-chat suggestion.
- Handoff summary template (`references/handoff.md`).
- Output savings: edit instead of regenerating, no unrequested files.
- Reliability rules: never cut figures, code or decision-changing warnings.

## [1.0.0] - 2026-11-21
- First published version of the skill.
- Added LICENSE.md (English and Spanish) and README.md.
